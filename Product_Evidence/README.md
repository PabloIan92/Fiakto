# Product evidence

This folder contains the evidence available for the Fiakto hackathon prototype.

- `fiakto-product-evidence.png` shows the application running locally.
- `fiakto-five-year-projection.csv` contains the transparent five-year planning model used in the submission.

Fiakto is a pre-revenue prototype. A billable Google Cloud deployment and a live Gemini API call were not completed in this iteration, so this repository does not claim Google Cloud invoices, Gemini observability dashboards, production users, or revenue that do not exist.
